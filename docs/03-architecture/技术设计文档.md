## 四、数据模型

### 4.1 核心实体

```
ChildProfile (孩子档案)
├── id: string (PK)
├── name: string
├── avatar: string
├── age: number
└── createdAt: number

LearningProgress (学习进度)
├── child_id: string (FK→ChildProfile)
├── module: ModuleType (character|pinyin|math|reading|writing)
├── item_id: string (FK→学习内容ID)
├── status: LearningStatus (new|learning|practicing|mastered|review)
├── mastery_level: number (0-100)
├── review_stage: number (艾宾浩斯复习阶段 0-7)
├── consecutive_correct: number
├── first_learned: timestamp
├── last_reviewed: timestamp
├── next_review_date: timestamp
└── review_count: number

DailyStats (每日统计)
├── child_id: string + date: string (复合PK)
├── total_time: number (秒)
├── items_learned: number
├── items_reviewed: number
└── avg_score: number
```

### 4.2 艾宾浩斯复习间隔

| 阶段 | 间隔 |
|------|------|
| Stage 0 | 5 分钟 |
| Stage 1 | 30 分钟 |
| Stage 2 | 12 小时 |
| Stage 3 | 1 天 |
| Stage 4 | 2 天 |
| Stage 5 | 4 天 |
| Stage 6 | 7 天 |
| Stage 7 | 15 天（长期记忆） |

**升降逻辑**：得分≥80%→进入下一阶段，得分<60%→回退前一阶段，60-79%→当前阶段重新计算

## 五、数据库设计

### 5.1 SQLite 表结构

```sql
-- 学习进度表
CREATE TABLE progress (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  child_id TEXT NOT NULL,
  module TEXT NOT NULL,
  item_id TEXT NOT NULL,
  status TEXT DEFAULT 'new',
  first_learned INTEGER,
  last_reviewed INTEGER,
  review_count INTEGER DEFAULT 0,
  consecutive_correct INTEGER DEFAULT 0,
  mastery_level INTEGER DEFAULT 0,
  next_review_date INTEGER,
  review_stage INTEGER DEFAULT 0,
  UNIQUE(child_id, module, item_id)
);

-- 每日统计表
CREATE TABLE daily_stats (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  child_id TEXT NOT NULL,
  date TEXT NOT NULL,
  total_time INTEGER DEFAULT 0,
  items_learned INTEGER DEFAULT 0,
  items_reviewed INTEGER DEFAULT 0,
  avg_score REAL DEFAULT 0,
  UNIQUE(child_id, date)
);

-- 学习日志表
CREATE TABLE learning_log (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  child_id TEXT NOT NULL,
  module TEXT NOT NULL,
  item_id TEXT NOT NULL,
  action TEXT NOT NULL,
  score INTEGER,
  timestamp INTEGER NOT NULL
);

-- 孩子档案表 (Android 新增)
CREATE TABLE profiles (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  avatar TEXT NOT NULL,
  age INTEGER NOT NULL,
  created_at INTEGER NOT NULL
);
```

## 七、状态管理

### 7.1 Store 职责

| Store | 职责 | 持久化 |
|-------|------|--------|
| `useUserStore` | 孩子档案 CRUD、当前选中孩子 | SQLite + localStorage |
| `useProgressStore` | 学习进度、每日统计、星星数、连续天数 | SQLite + localStorage |
| `useAdminStore` | 管理员模式开关 | localStorage |
| `useAppStore` | 全局 UI 状态（全屏、庆祝动画） | 无（内存） |

### 7.2 Zustand 使用规范

```typescript
// 选择器模式：避免返回新对象/数组（防止无限循环）
const progress = useProgressStore(s => s.progress)           // ✅ 引用不变
const isAdmin = useAdminStore(s => s.isAdmin)                // ✅ 原始值

// 使用 useMemo 包装派生数据
const learnedIds = useMemo(() =>
  new Set(progress.filter(p => p.status !== 'new').map(p => p.item_id)),
[progress])
```

## 十、Canvas 写字系统

### 10.1 米字格结构

```
┌──────────────────────────┐
│ ╲          │          ╱ │  ← 外框 (橙色)
│   ╲        │        ╱   │  ← 虚线内框 (金色)
│     ╲      │      ╱     │
│       ╲    │    ╱       │
│───────────┼───────────│  ← 横/竖中线 + 对角线
│       ╱    │    ╲       │
│     ╱      │      ╲     │
│   ╱        │        ╲   │
│ ╱          │          ╲ │
└──────────────────────────┘
        ┌──────────┐
        │ 浅灰底字  │  ← 70% 大小楷体参考字
        │   永     │
        └──────────┘
```

### 10.2 技术参数

| 参数 | 值 |
|------|-----|
| Canvas 尺寸 | 260×260 CSS px |
| Retina 缩放 | 2× (520×520 实际像素) |
| 笔触颜色 | #2D3436 |
| 笔触宽度 | 5px |
| 参考字体 | KaiTi, STKaiti, 楷体, 70%大小 |
| 坐标计算 | `(client - rect.left) * (canvasSize / rect.width)` |

## 十一、语音合成（TTS）

### 11.1 实现在 `src/renderer/utils/helpers.ts`

```typescript
// 核心函数
speakText(text: string, rate = 0.8): Promise<void>
  ├── 数学符号转中文: -→减, +→加, =→等于, ?→多少
  ├── ensureVoices(): 等待 Chrome 异步加载
  ├── getChineseVoice(): zh-CN > zh-* > 中文/Chinese
  └── SpeechSynthesisUtterance(lang='zh-CN', rate, pitch=1.1)

stopSpeaking(): 取消当前语音
```

### 11.2 使用场景

| 场景 | rate | 说明 |
|------|------|------|
| 拼音发音 | 0.6 | 慢速，清晰 |
| 故事朗读 | 0.75 | 适中语速 |
| 题目朗读 | 0.7 | 标准语速 |

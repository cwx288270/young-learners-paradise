# 幼小衔接学习乐园 — 产品功能文档

## 一、产品概述

**产品名称**：幼小衔接学习乐园

**产品定位**：面向 3-7 岁学龄前及小学低年级儿童的互动式学习应用，覆盖拼音、数学、识字、阅读、写字五大核心学科，结合游戏化交互与科学的艾宾浩斯复习体系。

**运行平台**：
| 平台 | 形态 |
|------|------|
| Web | 浏览器直接访问 |
| Windows/macOS | Electron 桌面应用 |
| Android | Capacitor 打包 APK |

**设计理念**：以关卡地图+游戏化的方式组织学习内容，遵循"认识→练习→应用"的认知规律，每步操作均有动画反馈。

---

## 二、用户角色

| 角色 | 功能 |
|------|------|
| **小朋友** | 学习拼音、数学、汉字、阅读、写字，获得星星奖励，解锁新关卡 |
| **家长** | 通过密码(1234)进入家长中心，查看学习报告，设置每日时长，导出数据 |
| **管理员** | 切换管理模式，绕过所有关卡锁定自由测试任意内容 |

## 六、数学山（🏔️ 数学）

### 6.1 登山关卡（10 关）

| 关卡 | 内容 | 题量 | 教学法 |
|------|------|------|--------|
| 第1关 | 10以内加法 | 36题 | 积木可视化 |
| 第2关 | 10以内减法 | 45题 | 积木可视化 |
| 第3关 | 凑十法 | 24题 | 凑十口诀+分步演示 |
| 第4关 | 20以内进位加法 | 26题 | 凑十法应用 |
| 第5关 | 破十法 | 21题 | 破十口诀+分步演示 |
| 第6关 | 20以内退位减法 | 36题 | 破十法应用 |
| 第7关 | 50以内加减法 | 267题 | 竖式+口算 |
| 第8关 | 图形与空间 | 25题 | 彩色图形可视化 |
| 第9关 | 规律与逻辑 | 25题 | 图案+数字规律 |
| 第10关 | 生活应用题 | 20题 | 情景故事 |

**总题量**：572题（含自动生成的加减法配对）

**解锁规则**：前一关完成 50% 后解锁下一关（管理员模式下全部解锁）

### 6.2 学习流程

1. **口诀学习**（方法类关卡首次进入）→ 可关闭的横幅展示口诀和概念
2. **互动答题** → 4 选 1 选择题，正确进入下一题，错误有提示
3. **图形题** → 彩色可视化图形（红色圆形、蓝色正方形、绿色三角形等）
4. **规律题** → 大号字符展示规律图案
5. **解析提示** → 连续答错 2 次后显示解题思路

### 6.3 闯关挑战

- **登山模式**：15 题连续作答
- **进度可视化**：5 级山形图，正确率决定登顶高度
- **评级**：⭐ 3星(≥90%) ⭐⭐ 2星(≥70%) ⭐⭐⭐ 1星(≥50%)

## 七、识字森林（🌳 识字）

### 7.1 关卡地图（30 关）

- 每关 10 个字，共 300 个关卡任务（基于 3000 字库）
- 显示进度环（百分比）
- 支持快捷操作：认字 / 练习 / 写字 / 听音

**解锁规则**：完成前一关所有字后解锁下一关

### 7.2 学习流程（四步法）

1. **认识字形** → 大字展示汉字 + 拼音 + 字源演变提示 + 5 个组词（带拼音可点击朗读）
2. **互动练习** → 选择题：听音选字 / 看字选拼音 / 看拼音选字（3 种轮换）
3. **书写练习** → Canvas 描红，米字格参考
4. **学以致用** → 用已学字组成的短句阅读

### 7.3 功能入口

| 入口 | 功能 |
|------|------|
| 认字 | 进入学习流程 |
| 练习 | 选择题巩固（5 题） |
| 写字 | Canvas 描红 |
| 听音 | 听音辨字测试 |

- **自动朗读**：切换到当前句自动播放中文语音
- **点击跳转**：任意点击某句即跳转+朗读
- **阅读答题**：读完所有句子后进入理解题（4选1）

**评级**：⭐ 3星(≥90%) ⭐⭐ 2星(≥70%) ⭐⭐⭐ 1星(≥50%)

## 九、写字坊（✏️ 写字）

### 9.1 字卡网格

- 5 列网格展示 50 个常用字
- 绿色边框 = 已写过，粉色边框 = 可练习，灰色 = 未解锁
- **解锁条件**：需先在识字模块学习过该字

### 9.2 描红练习

- **米字格**：Canvas 绘制的传统米字格背景
- **浅色底字**：灰色参考字迹供描红
- **笔顺提示**：当前笔画高亮，显示笔顺说明
- **逐笔引导**：完成一笔自动切换下一笔
- **触摸/鼠标**：同时支持触摸屏和鼠标操作
